# MDSyncView 快速上手（Windows 11）

这份指南写给第一次使用、不熟悉技术的朋友。全程只需要点鼠标，不用安装任何软件，不用打开命令行。整个过程大约 3 分钟。

## MDSyncView 是什么

它会自动找到你电脑里所有的 Markdown 笔记（`.md` 文件），在一个漂亮的窗口里展示出来，并且**实时同步**：你用任何软件修改、新增或删除笔记，窗口里的内容会自动跟着变，不用刷新。它只在你自己的电脑里运行，不会把文件上传到任何地方。

## 第 1 步：下载

1. 打开发布页面：<https://github.com/Anna-SAP/MDSyncView/releases/latest>
2. 在页面下方的 **Assets** 区域，点击 **`MDSyncView-win-x64.zip`** 下载（约 36 MB）。
3. 下载完成后，文件在「下载」文件夹里。

## 第 2 步：解压

1. 在「下载」文件夹里找到 `MDSyncView-win-x64.zip`。
2. 右键点击它，选择 **「全部解压缩…」**，再点 **「提取」**。
3. 得到一个文件夹，里面有这些内容（请保持它们在一起，不要单独移动其中某个文件）：
   - `MDSyncView.exe`：主程序，双击它启动
   - `MDSyncView-server.exe`：后台服务，由主程序自动启动
   - `client` 文件夹：界面文件
   - `README.txt`：简要说明

建议把整个文件夹移到一个固定的位置，例如 `D:\MDSyncView` 或「文档」里，方便以后找到。

## 第 3 步：启动

1. 双击 **`MDSyncView.exe`**。
2. **如果出现蓝色的「Windows 已保护你的电脑」提示**：这是因为程序还没有购买数字签名，Windows 对所有没签名的新程序都会这样提示。点击提示里的小字 **「更多信息」**，再点 **「仍要运行」** 即可。这个提示只会出现一次。
3. 如果弹出防火墙询问，点「允许访问」或直接关闭都可以。程序只在你的电脑内部通信，不需要联网。
4. 几秒钟后：
   - 屏幕右下角会弹出气泡「MDSyncView 正在后台运行」；
   - 一个 MDSyncView 窗口会自动打开。

第一次启动时，程序会在后台把整块硬盘扫描一遍来找笔记。这需要几分钟（笔记越多越久），期间窗口已经可以正常使用，左侧的文件列表会一点点变多，底部状态栏会显示扫描进度。以后再启动就只需要几秒钟。

## 第 4 步：认识窗口

- **左侧**是文件区，顶上有 5 个小图标可以切换：
  - 文件夹图标：按目录浏览全部笔记
  - 时钟图标：最近修改过的笔记，刚刚有变化的会带绿点
  - 放大镜图标：全文搜索，支持中文
  - `#` 图标：按标签浏览
  - 波形图标：实时变更记录
- **中间**是笔记内容，图片、表格、流程图、公式、表情符号都会正常显示。
- **右侧**是当前笔记的目录（大纲），点一下就能跳到对应段落。

试一试实时同步：用任何编辑器（记事本也行）打开一篇笔记，改几个字并保存，回到 MDSyncView 看，内容已经自动更新了，而且阅读位置没有变。

## 第 5 步：几个最常用的操作

| 想做什么 | 怎么做 |
| --- | --- |
| 快速打开某篇笔记 | 按 `Ctrl + P`，输入文件名的几个字，回车 |
| 搜索笔记内容 | 按 `Ctrl + Shift + F`，输入关键词 |
| 切换深色 / 浅色界面 | 点左下角的月亮 / 太阳图标 |
| 用其他软件打开这篇笔记 | 点笔记上方的「用默认程序打开」图标，或按 `Ctrl + E` |
| 在文件夹里找到这个文件 | 点笔记上方的「在资源管理器中显示」图标 |
| 放大 / 缩小文字 | `Ctrl + =` 放大，`Ctrl + -` 缩小，`Ctrl + 0` 还原 |
| 查看全部快捷键 | 按 `?` |

## 找到托盘图标

程序启动后会常驻在**任务栏右下角的通知区域**（时间旁边）。Windows 11 默认会把新图标藏在一个小箭头 **`^`** 里：

1. 点击任务栏右下角的 **`^`**，就能看到 MDSyncView 的蓝色 M 图标。
2. 想让它一直显示：按住图标，把它拖到任务栏时间旁边即可。

图标的用法：

- **双击**图标：打开（或重新打开）窗口
- **右键**图标：菜单里有「打开 MDSyncView」「重新扫描」「打开数据目录」「查看服务日志」「重启服务」「退出 MDSyncView」

## 关闭与退出

- 关掉 MDSyncView 窗口后，程序**仍在后台运行**（图标还在托盘里），这样再次打开会非常快。想再打开窗口，双击托盘图标即可。
- 要彻底退出：右键托盘图标，选 **「退出 MDSyncView」**。

## 只看某些文件夹（可选）

默认会扫描整块硬盘。如果你只想看某几个文件夹里的笔记：

1. 点窗口左下角的 **齿轮（设置）** 图标。
2. 取消勾选「自动：接管本机所有固定磁盘」。
3. 点「添加目录…」，选择你的笔记文件夹，可以添加多个。
4. 点「保存并应用」。

## 开机自动启动（可选）

1. 右键 `MDSyncView.exe`，选「显示更多选项」→「创建快捷方式」。
2. 同时按 `Win + R`，输入 `shell:startup`，回车，会打开「启动」文件夹。
3. 把刚才的快捷方式拖进这个文件夹。以后开机就会自动运行并常驻托盘。

## 遇到问题

| 现象 | 处理 |
| --- | --- |
| 双击后没有窗口 | 点任务栏右下角 `^`，双击 MDSyncView 图标 |
| 提示「找不到 MDSyncView-server.exe」 | 解压时文件被拆开了，请重新解压整个 zip，保持文件夹完整 |
| 窗口打开了但一片空白 | 关掉窗口，右键托盘图标选「重启服务」，再双击图标 |
| 想看到底发生了什么 | 右键托盘图标 → 「查看服务日志」 |
| 想彻底卸载 | 先从托盘退出，删除解压出来的文件夹；再删除 `C:\Users\你的用户名\AppData\Local\MDSyncView`（存放索引和设置，可在文件资源管理器地址栏输入 `%LOCALAPPDATA%\MDSyncView` 直达） |

## 一点说明

- 程序需要读取你的笔记文件才能显示它们，但**只读不写**，不会修改、移动或删除任何文件。
- 所有数据都在你的电脑上，没有账号，不联网。
- 第一次扫描后会在 `%LOCALAPPDATA%\MDSyncView` 里建立一个索引文件，用来实现快速搜索；笔记很多时它可能有几百 MB，属于正常现象。
